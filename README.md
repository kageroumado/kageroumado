# Mado Kagerou

Mac apps that extend system behavior, alongside research in computational pharmacology and LLM interpretability. The work includes a separate desktop for AI agents, Steam rendered through native WebKit, and personal videos in Apple’s wallpaper system.

[Apps and writing](https://kagerou.glass) · [About and research](https://kagerou.glass/about/) · [ORCID](https://orcid.org/0009-0005-5962-9254) · [Contact](mailto:mail@kagerou.glass)

## Apps

| App | What it does |
|---|---|
| [Rocuronium](https://kagerou.glass/rocuronium/) | Separate agent desktop, local models for finding UI elements, and verified interaction results |
| [Sevoflurane](https://kagerou.glass/sevoflurane/) | Native WebKit interface for Windows Steam, with resizable and upscaled game windows |
| [Phosphene](https://kagerou.glass/phosphene/) | Personal videos in the system wallpaper picker, with desktop and lock-screen playback |
| [Adrafinil](https://kagerou.glass/adrafinil/) | Keeps a closed-lid Mac awake during agent work and releases it when the turn ends |
| [Refrax](https://kagerou.glass/refrax/) | Per-tab WebKit or Chromium, shared browser state and CLI control |
| [Piru](https://kagerou.glass/piru/) | Dose and observation timelines with an offline, source-selectable substance reference |
| [Rilmazafone](https://github.com/kageroumado/rilmazafone) | Visual DMG design and release publishing in one saved plan |
| [Coluracetam](https://github.com/kageroumado/coluracetam) | The same Markdown rendering in its editor, Quick Look and Finder thumbnails |
| [Dantrolene](https://github.com/kageroumado/dantrolene) | Network-based lock prevention with display dimming |
